## Overview

This project implements a Recurrent Neural Network (RNN) to perform sequence prediction and time-series forecasting. The model learns patterns from sequential data to predict future values, making it suitable for applications such as stock price prediction, weather forecasting, and demand estimation.

## Features
Data preprocessing and normalization
RNN model implementation using TensorFlow/Keras
Time-series prediction and forecasting
Performance evaluation using MSE and RMSE
Visualization of actual vs. predicted values

## Technologies Used
Python
TensorFlow/Keras
NumPy
Pandas
Matplotlib
Scikit-learn

## Applications
Stock Market Prediction

## Conclusion

This project demonstrates how RNNs can effectively learn temporal patterns in sequential data and perform accurate time-series predictions while highlighting their strengths and limitations in real-world forecasting tasks.
